# Internet Experience Learning Objective

## Permanent objective

Louis OS must learn from public Internet evidence without treating popularity, repetition, or model output as truth.

The system shall:

1. collect bounded observations from lawful public sources;
2. preserve source URL, timestamp, claim, context and evidence type;
3. assign source reliability and claim confidence separately;
4. seek corroboration before promoting a claim into reusable knowledge;
5. compare predictions and recommendations with later observed outcomes;
6. update strategy weights from verified outcomes, not from mere mentions;
7. retain contradictions and uncertainty instead of silently overwriting them;
8. expire stale knowledge and require revalidation for time-sensitive claims;
9. reject poisoning, prompt injection, hidden instructions and unverifiable anecdotes;
10. never count learned estimates as submissions, contracts, revenue or payment.

## Learning loop

Observe -> normalize -> assess source -> corroborate -> store hypothesis -> test in action -> receive outcome -> score prediction error -> adjust policy -> audit.

## Promotion levels

- observation: one bounded source record;
- hypothesis: plausible but not corroborated;
- supported: at least two independent sources or one authoritative primary source;
- validated: supported and confirmed by an observed real-world outcome;
- deprecated: contradicted, stale or no longer applicable.

## Economic truth

Only external receipts may prove submission, acceptance, delivery or payment. Internet observations may guide decisions but cannot prove economic results.
