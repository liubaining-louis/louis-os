# Decision — Software micro-mission delivery lane

## Decision

Louis OS treats small website, frontend, Python automation, API integration and static deployment work as a first-class `cash_first` lane when the public scope is explicit, remotely deliverable, payable, testable and estimated at no more than 16 hours.

## Validated capabilities

| Capability | Default scope | Maximum effort | Internal price guidance |
|---|---|---:|---:|
| `static_website_delivery` | responsive landing page or up to five static pages | 16 h | 150–800 EUR |
| `frontend_bug_fix` | one bounded HTML/CSS/JavaScript defect | 8 h | 80–350 EUR |
| `python_automation_delivery` | deterministic file or CSV automation | 12 h | 120–500 EUR |
| `api_integration_delivery` | one documented API or webhook flow | 16 h | 200–600 EUR |
| `deployment_and_validation` | static package, local validation and reversible instructions | 6 h | 50–150 EUR |

Price ranges are internal guidance only. They are not offers, pipeline, contracts or revenue. The platform-displayed budget remains the authoritative payment evidence for a concrete opportunity.

## Required delivery evidence

Every software delivery must include:

- a normalized scope and explicit boundaries;
- source files;
- fixtures or sample input when applicable;
- deterministic tests or validation checks;
- a manifest and SHA-256 hashes;
- an external submission/deployment flag set to `false` until a receipt exists;
- instructions for the smallest remaining human gate.

## Demonstration pack

The repository generates three reusable demonstrations during each universal cycle:

1. a dependency-free responsive landing page with local validation and static deployment instructions;
2. a Python CSV normalization and deduplication utility with sample input and expected output;
3. an injectable HTTPS JSON API client with timeout, error behavior and offline tests.

These demonstrations prove bounded capability only. They are not client work and do not count as monetization.

## Fail-closed scope guard

Reject rather than expand capability when the request includes:

- a complete application, marketplace, SaaS, ecommerce system or clone;
- copied protected design or content;
- unlimited revisions, ongoing staffing or 24/7 support;
- credential collection, authentication bypass or unauthorized access;
- off-platform payment, deceptive traffic or fake engagement;
- payment, banking, identity or production-database changes without a dedicated review;
- a material scope that cannot reasonably fit within 16 hours.

## External gates

Account creation, terms acceptance, KYC, payout configuration, DNS changes, production deployment, secret access, billing changes and contract signature remain human gates. Louis OS prepares all reversible artifacts first and asks only for the exact final action.

## Economic truth

Demo generation, proposal drafting, capability validation and internal price guidance cannot increment submissions, conversions, weighted pipeline or revenue. Only receipt-backed external events may change those fields.
