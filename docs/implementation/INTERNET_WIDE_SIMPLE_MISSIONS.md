# Internet-wide simple missions operating model

Louis OS searches an expanding mesh of official public or authorized sources rather than one marketplace. The operating model is:

1. discover small remote missions across independent sources;
2. require authoritative budget/rate, deadline, competition and payment evidence;
3. reject physical, unsafe, sensitive, long-term or unverifiable work;
4. route validated capabilities immediately and create bounded capability tasks for the rest;
5. prepare a complete proposal dossier before any account or terms gate;
6. request only the final minimal human action;
7. record external submissions and revenue only from verifiable receipts.

The source mesh currently includes canonical GitHub bounty sources, Freelancer.com, Guru, official participant-study platforms when authorized, and strategic public challenge sources. Additional public marketplace adapters are added independently so one empty or unavailable source does not stop the cycle.
